# Desafio Pandas: Análise Estatística de Dataset de Atividades

Este repositório documenta a solução para um desafio de análise de dados usando a biblioteca Pandas. O objetivo é carregar um dataset, explorá-lo, limpar os dados e calcular as principais medidas de tendência central e variabilidade.

O dataset utilizado foi o `data.csv`.
