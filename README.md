## Lógica de Programação - Repositório da Disciplina

---

Bem-vindo(a) ao repositório oficial da disciplina de **Lógica de Programação em Python**!

Este espaço será utilizado para centralizar todo o material, exercícios, exemplos de código e o desenvolvimento do nosso **Projeto de Conclusão**.

### Conteúdo

Aqui você encontrará:

* **Materiais de Aula:** Slides, PDFs e anotações relevantes.
* **Exercícios:** Listas de exercícios e códigos para prática.
* **Exemplos:** Códigos de demonstração e exemplos práticos dos conceitos.

### Projeto de Conclusão

Ao longo do semestre, aplicaremos os conceitos aprendidos no desenvolvimento de um **projeto prático**. Este projeto é o trabalho de conclusão da disciplina e deve demonstrar o domínio dos fundamentos da lógica de programação.

* **Objetivo:** Consolidar o aprendizado, aplicando conceitos como variáveis, estruturas de controle (condicionais e repetição), funções e estruturas de dados básicas.
* **Entrega:** O projeto final será entregue ao fim do semestre. Fique atento(a) aos prazos e requisitos que serão detalhados na pasta específica do projeto.

### Como Contribuir (ou Acessar)

1.  **Clone o Repositório:** Use o comando `git clone https://github.com/HenriqueCliri/logica_de_programacao` para ter uma cópia local de todos os arquivos.
2.  **Mantenha-se Atualizado:** Use `git pull` regularmente para garantir que você tenha a versão mais recente dos materiais e requisitos.
